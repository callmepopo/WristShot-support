# 腕拍 · WristShot 支持

腕拍是 Apple Watch 上的独立运动相机录像遥控工具，通过蓝牙直接连接 Osmo Nano。

## 开始使用

1. 确保 Nano 已激活、具备足够电量，并处于可连接的普通视频模式。
2. 在 Apple Watch 打开腕拍，允许蓝牙访问，点击“搜索相机”。
3. 选择你的相机；首次连接若相机提示授权，请在相机上确认。
4. 等待真实状态更新后，点击“开始录像”；录像时点击“停止录像”。
5. 支持系统双指互点的手表可将该手势用于当前主要操作，需要 watchOS 11 或更新版本及相应系统设置。其他手表使用按钮。

拍摄期间无需 iPhone 中转，Nano 多功能图传模块可分离并关机。相机需保持可连接状态，腕拍需在手表前台。最低系统 watchOS 9。

## 常见问题

**找不到相机？** 检查相机电量、距离和蓝牙连接状态；相机若已连接其他遥控设备，请先释放占用，再重新搜索。首次激活和固件升级按相机官方流程完成。

**按钮暂时不可点？** 腕拍须取得配对授权和最新真实录像状态，才能发送启停指令。保持前台，刷新状态或重新连接。

**没有显示 4K30？** 仅在成功读取可靠参数后显示分辨率/帧率，不使用估算值。录制时长在录像状态确认后显示。

**所有 Apple Watch 都支持双指互点吗？** 否。原生系统双指互点依赖支持该功能的机型和系统，S7/S8 可使用按钮；辅助触控需要另行设置及验证。

**支持其他机型吗？** 当前主要支持 Osmo Nano。App 中的 Action 5 Pro 路径仍待完整真机验证；不承诺其他机型兼容，不支持 Pocket 3。
