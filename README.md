# 腕拍 · WristShot 支持

腕拍是 Apple Watch 上的独立运动相机录像遥控工具，通过蓝牙直接连接 DJI 运动相机。

## 适配范围

- 相机：Osmo Nano、Osmo Action 5 Pro；0.4.0 起新增 Osmo Action 4、Osmo Action 6、Osmo 360。Pocket 系列不支持。
- 手表：0.4.0 起要求 watchOS 11 及以上，Apple Watch Series 6 及以上、SE 第二代及以上、Ultra 全系。
- 双指互点：Series 9 及以上、Ultra 2 及以上、SE 第三代原生支持；Series 6–8、SE 第二代、Ultra 第一代可用辅助触控手势。

## 开始使用

1. 确保相机已激活、固件为最新、具备足够电量，并处于视频模式。
2. 在 Apple Watch 打开腕拍，允许蓝牙访问，点击“搜索相机”。
3. 选择你的相机；首次连接若相机提示授权，请在相机上确认。
4. 等待真实状态更新后，点击“开始录像”；录像时点击“停止录像”。
5. 支持双指互点的手表可直接用该手势开始/停止录像；其他手表使用按钮或辅助触控手势。

拍摄期间无需 iPhone 中转，Nano 多功能图传模块可分离并关机。相机需保持可连接状态，腕拍需在手表前台。

## 常见问题

**找不到相机？** 检查相机电量、距离和蓝牙连接状态；相机若已连接其他遥控设备，请先释放占用，再重新搜索。首次激活和固件升级按相机官方流程完成。

**按钮暂时不可点？** 腕拍须取得配对授权和最新真实录像状态，才能发送启停指令。保持前台，刷新状态或重新连接。

**没有显示 4K30？** 仅在成功读取可靠参数后显示分辨率/帧率，不使用估算值。录制时长在录像状态确认后显示。

**所有 Apple Watch 都支持双指互点吗？** 否。原生双指互点仅限 Series 9 及以上、Ultra 2 及以上、SE 第三代；其他手表可在“设置 → 辅助功能 → 辅助触控”中开启，用握拳/捏合手势操作，或直接点按钮。

**支持其他机型吗？** 见上方“适配范围”。如手表提示“暂未适配（设备号 0x….）”，欢迎通过 App 内“意见反馈”提交截图。

## 反馈与联系

推荐使用 App 内“意见反馈”，用手机扫码填写问卷（约 1 分钟）。也可[在 GitHub 提交问题或功能建议](https://github.com/callmepopo/WristShot-support/issues/new)，请说明手表型号、watchOS 版本、相机型号和固件版本、操作步骤。公开问题中不要提交序列号、配对凭据或其他私人信息。
